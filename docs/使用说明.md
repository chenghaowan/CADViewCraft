# CADViewCraft 使用说明

一款轻量 3D CAD 查看器:打开 STEP/IGES 等模型,查看装配结构、做断面剖切、进行测量。

---

## 一、启动

**方式一:命令行直接打开文件(推荐)**

```bash
cd D:\study.git\CADViewCraft
target\release\cadviewcraft.exe D:\study.git\testdata\Part1.stp
```

**方式二:先启动,再打开文件**

```bash
target\release\cadviewcraft.exe
```

启动后把模型文件**拖进窗口**,或点工具栏左上角 **文件 → 导入…**。

**方式三:开发调试运行**

```bash
cargo run --release -- D:\study.git\testdata\Part1.stp
```

> 提示:首次使用需先构建一次(`cargo build --release`,需要几分钟);日常直接运行 `target\release\cadviewcraft.exe` 即可,秒开。

**支持的文件格式**(与 SolidCraft 同一套导入清单):

- B-rep:`.step` / `.stp`、`.igs` / `.iges`、FreeCAD `.fcstd`、Rhino `.3dm`、CATIA V5 `.CATPart`
- 网格:`.stl`、`.3mf`、`.obj`、`.glb` / `.gltf`(嵌入缓冲;外部 `.bin` 不支持)

CATPart 由本程序的转换支路(cadmpeg 清洁室编解码器)解码重述为 STEP 后走 STEP 导入链,并在源文件旁生成同名 `.stp` 中间文件(可检视、可复用;旁有非本程序生成的同名文件时不覆盖并警告);NX、Creo、SolidWorks 等其余专有格式不支持,请先在原软件中另存为 STEP。

## 二、界面布局

界面与 SolidCraft 同款:自绘标题栏 + 页签式 ribbon + 浮动圆角卡片,视口全出血铺在底层。

```
┌─────────────────────────────────────────────────┐
│ 应用栏:Logo CADViewCraft │ 文件 │ …      设置 □ □ ✕ │ ← 自绘标题栏
├─────────────────────────────────────────────────┤
│ ribbon:页签[视图 | 检查] + 图标按钮(组间竖线)       │
├────────┬─────────────────────────┬──────────────┤
│ 模型树  │        3D 视口(全出血)   │  属性卡片     │
│ 浮动卡片│  右上角:导航罗盘          │ (浮动卡片,    │
│        │  底部:消息 toast          │  可开关)      │
└────────┴─────────────────────────┴──────────────┘
```

- **自绘标题栏**:窗口没有系统标题栏;按住应用栏空白处拖动窗口,双击最大化/还原,窗口边缘 8px 内可缩放,右上角三个按钮最小化/最大化/关闭。
- **ribbon 页签**:**视图**(适配/前视/等轴测/属性)与**检查**(建点/轴/坐标系/点距/体距/质心/断面)两页;按钮激活时以蓝色描边高亮。
- **没有状态栏**:工具进行中的提示显示在**视口左上角**;打开完成/测量结果等一次性消息在视口**底部以 toast 弹出**,6 秒后自动消失。

## 三、打开与最近文件

| 操作 | 方法 |
|---|---|
| 打开文件 | 应用栏 **文件 → 导入…**,或把文件拖进窗口 |
| 打开最近文件 | 应用栏 **文件** 菜单底部列出最近 10 个文件,点击即开 |
| 退出 | 应用栏 **文件 → 退出**,或右上角 ✕ |

打开文件后,底部 toast 会显示文件路径、格式、实体数、三角形数和导入耗时。

---

## 四、视图操作

| 操作 | 方法 |
|---|---|
| 旋转 | 视口内**按住左键拖动** |
| 平移 | **按住中键或右键拖动** |
| 缩放 | **滚轮**(指向哪里缩向哪里附近) |
| 适配视图(模型撑满窗口) | ribbon **视图** 页签 → **适配** |
| 标准视角 | **视图** 页签 → **前视**;等轴测在 **等轴测** |
| 按轴切换视角 | 点视口**右上角导航罗盘**的轴尖(X/Y/Z 正方向圆盘、负方向圆环):点 +Z 从顶往下看,点 -Y 从前看,以此类推;再点同一轴尖从反方向看 |
| 辨别方位 | 导航罗盘(X 红、Y 绿、Z 蓝),随视角实时转动 |

## 五、模型树与几何特征(左侧浮动卡片)

- 树中列出装配结构:产品 → 子件 → 实体(PartBody)。
- **点眼睛图标** = 显示/隐藏该节点(睁眼可见、闭眼隐藏,视口实时生效)。
- **点击实体名字** = 选中该实体(与视口选择联动,高亮显示)。
- 隐藏的实体无法被选中;若选中的对象被隐藏,选中自动取消。

**几何特征**(卡片下部,有测量或构造结果时才出现):

- 分**测量**(点距/体距)与**构造**(点/轴/坐标系)两组,自动列出当前全部结果;
- **点眼睛** = 显示/隐藏该特征在视口的标记与标签;
- **点 ×** = 删除该特征(测量被清空、构造被移除);
- **点名字** = 选中该特征(视口中改为蓝色强调高亮;与模型树选中互斥,再点一次取消);
- 打开新文件会清空全部测量与构造,该区域随之隐藏。

## 六、选择

| 操作 | 结果 |
|---|---|
| **单击**模型表面 | 选中一个**面**(橙色高亮) |
| **双击**模型表面 | 选中整个**实体**(蓝色高亮) |
| 单击空白处 | 取消选择 |
| 点击模型树中的实体名 | 选中整个实体 |

选中的对象会同步显示在右侧属性面板的"选中"区。

## 七、断面(剖切)

1. 点 ribbon **检查** 页签 → **断面**,开启剖切并弹出**断面分析浮窗**(默认自顶向下剖掉一半):
   - **方向**:`-Z / +Z / +X / +Y` 选择剖切朝向,**反转** 取反法向;
   - **深度**:拖动滑条控制剖掉多少(左=不剖,右=全剖);
   - **剖面填充线**:勾选后截面上显示斜线填充;
   - **关闭断面**:结束剖切并关浮窗;浮窗右上角 ✕ 或 **取消** 只关浮窗(取消按钮同义)。
2. 再点 ribbon 的 **断面** 按钮也可整体关闭剖切。

剖切是实时的,拖动深度滑条即可"扫描"模型内部。被剖掉的部分点不到、选不中。

---

## 八、测量

所有测量在 ribbon **检查** 页签,结果显示为视口内的绿色标注线和数值标签,完成时底部弹出 toast,并在属性卡片同步显示;同时自动列入左侧卡片的**几何特征**区(见第五节),可显隐、删除、选中。

**点-点距离**
1. 点 **点距**(按钮高亮表示测量中);
2. 在模型上点第一个点(出现绿色十字标记);
3. 再点第二个点 → 显示两点连线和距离;
4. 按 **Esc** 取消;新的测量会替换上一次的结果。

**体-体距离**(两实体间最小距离)
1. 点 **体距**;
2. 依次点两个实体(点第一个后整体变浅蓝提示);
3. 计算完成后显示最小距离连线与数值(数值带 `≈` 表示近似值)。

**质量属性(体积/表面积/质心)**
- **双击**选中一个实体,属性面板自动显示:体积、表面积、包围盒尺寸、质心坐标。
- 大型装配首次计算需等几秒,面板显示"计算中…"。

**面信息(面积/法向)**
- **单击**选中一个面,属性面板显示:面积、法向(仅平面)、面的质心。

**质心标记**
- 点 **质心** 按钮开启:选中实体上显示紫色十字质心标记和坐标标签;再点关闭。

## 九、构造(点 / 轴 / 坐标系)

ribbon **检查** 页签的构造按钮,用于在模型上放置参考几何,显示为橙色标记(坐标系为红X/绿Y/蓝Z三色轴);工具激活时视口左上角有常驻操作提示,**Esc** 取消。已放置的构造元素会自动列入左侧卡片的**几何特征**区(见第五节),可显隐、删除、选中:

**建点**(自动吸附)
- 依次优先吸附:**顶点** → **圆弧边的圆心** → **圆柱/圆锥/圆环/球面的圆心** → 都不是时取面命中点;
- 可连续点多个点,每个点自动编号 P1、P2…(十字标记 + 坐标标签);
- **Esc** 退出;打开新文件自动清空全部构造元素。

**两点轴**
- 点两个点(吸附规则同上),过两点作轴 A1(轴线两端各超模型尺度 1/4)。

**边轴**
- 点一条边:直边 → 沿边方向的轴;圆弧边 → 过圆心、沿圆弧平面法向的轴。

**圆柱轴**
- 点圆柱/圆锥/圆环面 → 该面的轴线。

**坐标系(对话框定义,默认关联)**
- 点 ribbon **坐标系** 弹出**定义坐标系**浮窗,「原点」「Z 方向」两个框默认进入拾取状态,在视口点击即填入;
  - 原点吸附:构造点 P{n} → 顶点 → 圆弧边的圆心 → 圆柱/圆锥/圆环/球面的圆心 → 面上任意点;
  - Z 方向吸附:构造轴 A{n} → 直边(沿边)→ 圆弧边(法向)→ 圆柱类面(轴向);也可点 **世界Z** 按钮直接用世界 Z(相当于以前的 Enter);
- **关联几何**默认勾选:坐标系记住拾取的引用,几何更新时轴系跟着重算(引用失效则保留最后位置);
- 取消勾选即**去关联**:原点/Z 方向变成数字框可编辑,坐标系不再随几何变化;
- 浮窗打开期间可实时看到三轴预览;**确定**落库,**Esc** 先退拾取、再关窗,**Enter** = 确定;
- 已建坐标系在几何特征列表中显示 **·关联** / **·独立** 后缀;**双击行名**重新打开浮窗修改(换引用、去关联或重新关联);删除被引用的构造点/轴时,引用它的坐标系会自动去关联并提示。

## 十、属性面板

右侧浮动卡片(用 **视图** 页签的 **属性** 按钮开关,点卡片标题行右侧的 **✕** 也可关闭)分两部分:

- **文件信息**:名称、格式(B-rep 文件显示 STEP schema,网格文件显示 STL/3MF/OBJ/glTF)、实体数、三角形数、整体包围盒;
- **选中**:当前选中对象的名字、类型(面/体),以及对应的测量结果。

## 十一、常见问题

- **界面是方框/乱码?** 程序内嵌 IBM Plex 界面字体,中文回退到系统字体(微软雅黑),请确认系统字体目录正常。
- **点"体积"一直显示计算中?** 大模型的质量属性计算需要时间,稍候片刻;期间可继续旋转视图。
- **文件打不开?** 确认是第一节列出的支持格式;打开失败的原因会以红点 toast 显示在视口底部。
- **窗口里看不到模型?** 点 **视图** 页签 → **适配**。
- **怎么切亮色主题?** 应用栏右上 **设置** 齿轮 → 主题 → 亮色(默认暗色,也可跟随系统)。
