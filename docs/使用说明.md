# CADViewCraft 使用说明

一款仿 Mayo 的 3D CAD 查看器:打开 STEP/IGES 模型,查看装配结构、做断面剖切、进行测量。

---

## 一、启动

**方式一:命令行直接打开文件(推荐)**

```bash
cd D:\study.git\CADViewCraft
target\release\cadviewcraft.exe D:\study.git\testdata\Part1.stp
```

**方式二:先启动,再打开文件**

```bash
target\release\cadviewcraft.exe
```

启动后把模型文件**拖进窗口**,或点工具栏左上角 **文件 → 打开…**。

**方式三:开发调试运行**

```bash
cargo run --release -- D:\study.git\testdata\Part1.stp
```

> 提示:首次使用需先构建一次(`cargo build --release`,需要几分钟);日常直接运行 `target\release\cadviewcraft.exe` 即可,秒开。

**支持的文件格式**:STEP(`.stp` / `.step`)、IGES(`.igs` / `.iges`)。
CATIA(`.CATPart`)等专有格式不支持,请先在原软件中另存为 STEP。

## 二、界面布局

```
┌─────────────────────────────────────────────────┐
│ 工具栏(ribbon):文件 │ 视图 │ 检查                │
│ 断面参数行(仅断面开启时出现)                       │
├────────┬─────────────────────────┬──────────────┤
│ 模型树  │        3D 视口           │  属性面板     │
│        │  (右上角:坐标轴指示)      │ (可用"属性"   │
│        │                         │  按钮开关)    │
├────────┴─────────────────────────┴──────────────┤
│ 状态栏:当前状态 / 操作提示                          │
└─────────────────────────────────────────────────┘
```

---

## 三、打开与最近文件

| 操作 | 方法 |
|---|---|
| 打开文件 | 工具栏 **文件 → 打开…**,或把文件拖进窗口 |
| 打开最近文件 | 工具栏 **文件** 菜单底部列出最近 10 个文件,点击即开 |
| 退出 | 工具栏 **文件 → 退出**,或直接关闭窗口 |

打开文件后,状态栏会显示文件路径、格式、实体数、三角形数和导入耗时。

---

## 四、视图操作

| 操作 | 方法 |
|---|---|
| 旋转 | 视口内**按住左键拖动** |
| 平移 | **按住中键或右键拖动** |
| 缩放 | **滚轮**(指向哪里缩向哪里附近) |
| 适配视图(模型撑满窗口) | 工具栏 **视图 → 适配** |
| 标准视角 | 工具栏 **视图 → 前视**;等轴测在 **视图 → 等轴测** |
| 辨别方位 | 视口**右上角**的坐标轴指示(X 红、Y 绿、Z 蓝),随视角实时转动 |

---

## 五、模型树(左侧)

- 树中列出装配结构:产品 → 子件 → 实体(PartBody)。
- **勾选/取消勾选** = 显示/隐藏该节点(视口实时生效)。
- **点击实体名字** = 选中该实体(与视口选择联动,高亮显示)。
- 隐藏的实体无法被选中;若选中的对象被隐藏,选中自动取消。

---

## 六、选择

| 操作 | 结果 |
|---|---|
| **单击**模型表面 | 选中一个**面**(橙色高亮) |
| **双击**模型表面 | 选中整个**实体**(蓝色高亮) |
| 单击空白处 | 取消选择 |
| 点击模型树中的实体名 | 选中整个实体 |

选中的对象会同步显示在右侧属性面板的"选中"区。

---

## 七、断面(剖切)

1. 点工具栏 **检查 → 断面**,开启剖切(默认自顶向下剖掉一半)。
2. 工具栏下方出现**断面参数行**:
   - **方向**:`-Z / +Z / +X / +Y` 选择剖切朝向;
   - **深度**:拖动滑条控制剖掉多少(左=不剖,右=全剖);
   - **剖面填充线**:勾选后截面上显示斜线填充。
3. 再次点击 **断面** 按钮关闭剖切。

剖切是实时的,拖动深度滑条即可"扫描"模型内部。被剖掉的部分点不到、选不中。

---

## 八、测量

所有测量在工具栏 **检查** 组,结果显示为视口内的绿色标注线和数值标签,并在属性面板同步显示。

**点-点距离**
1. 点 **点距**(按钮高亮表示测量中);
2. 在模型上点第一个点(出现绿色十字标记);
3. 再点第二个点 → 显示两点连线和距离;
4. 按 **Esc** 取消;新的测量会替换上一次的结果。

**体-体距离**(两实体间最小距离)
1. 点 **体距**;
2. 依次点两个实体(点第一个后整体变浅蓝提示);
3. 计算完成后显示最小距离连线与数值(数值带 `≈` 表示近似值)。

**质量属性(体积/表面积/质心)**
- **双击**选中一个实体,属性面板自动显示:体积、表面积、包围盒尺寸、质心坐标。
- 大型装配首次计算需等几秒,面板显示"计算中…"。

**面信息(面积/法向)**
- **单击**选中一个面,属性面板显示:面积、法向(仅平面)、面的质心。

**质心标记**
- 点 **质心** 按钮开启:选中实体上显示紫色十字质心标记和坐标标签;再点关闭。

## 九、构造(点 / 轴 / 坐标系)

工具栏 **构造** 组,用于在模型上放置参考几何,显示为橙色标记(坐标系为红X/绿Y/蓝Z三色轴):

**建点**(自动吸附)
- 依次优先吸附:**顶点** → **圆弧边的圆心** → **圆柱/圆锥/圆环/球面的圆心** → 都不是时取面命中点;
- 可连续点多个点,每个点自动编号 P1、P2…(十字标记 + 坐标标签);
- **Esc** 退出;打开新文件自动清空全部构造元素。

**两点轴**
- 点两个点(吸附规则同上),过两点作轴 A1(轴线两端各超模型尺度 1/4)。

**边轴**
- 点一条边:直边 → 沿边方向的轴;圆弧边 → 过圆心、沿圆弧平面法向的轴。

**圆柱轴**
- 点圆柱/圆锥/圆环面 → 该面的轴线。

**坐标系**
1. 点原点(吸附规则同建点);
2. 再拾取 **Z 方向**:直边(沿边)、圆弧边(法向)或圆柱类面(轴向);
   - 或直接按 **Enter** 用世界 Z;
3. 生成三色轴坐标系 C1(X = 世界 X 投影到垂直 Z 的方向)。

---

## 十、属性面板

右侧面板(可用 **检查 → 属性** 按钮开关)分两部分:

- **文件信息**:名称、格式(STEP schema)、实体数、三角形数、整体包围盒;
- **选中**:当前选中对象的名字、类型(面/体),以及对应的测量结果。

---

## 十一、常见问题

- **界面是方框/乱码?** 程序自动加载 Windows 系统字体(微软雅黑),请确认系统字体目录正常。
- **点"体积"一直显示计算中?** 大模型的质量属性计算需要时间,稍候片刻;期间可继续旋转视图。
- **文件打不开?** 确认是 STEP/IGES 格式;打开失败的原因会显示在状态栏。
- **窗口里看不到模型?** 点工具栏 **视图 → 适配**。
